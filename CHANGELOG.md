# Changelog

## 1.0.0 — 2026-11-06
- First release: guided interview, GitHub fetch (REST + optional GraphQL), evidence-graded analysis
  with JD matching, README metric and package detection, facts-only draft.
- Six ATS-safe templates (modern, classic, minimal, executive, academic, compact) plus bring-your-own.
- Renderer: HTML, PDF (Playwright / Chrome / WeasyPrint), DOCX, Markdown, TXT; auto-fit to page
  limit; promotions grouping; region-aware paper, naming and dates.
- ATS checker: parser-view scoring, exact-term gap detection, acronym and title tips, `--dump-text`.
- Cross-agent support: AGENTS.md, Claude Code plugin + `/make-cv`, Cursor, Copilot, Windsurf, Cline, Gemini.
